    Notes on accuracy

    Dates and figures were taken from the linked pages on the date shown above. The Meetup group page showed no upcoming events at that time. Some sources give slightly different dates for the Awards (ceremony 19 June, coverage published 22 June); this page uses the ceremony date. Always check the organiser’s page before travelling to an event.

    Independent information page, not affiliated with any organisation listed. Built with plain HTML, CSS and JavaScript. Content is loaded from data.json — edit that file to add or update events, news, awards, groups or sources. Upcoming events are also listed automatically from organiser calendars (events.auto.json, refreshed daily) — no need to edit that file by hand. To attach a photo to any event, news item or group, add an "image" field (a path such as images/events/your-file.jpg, relative to this page) and, ideally, an "imageAlt" description — both are optional, so entries without one render exactly as before.
